# Параметрическое ядро санскрита, извлеченное ИЗ СЛОВАРЯ (PWG)

_Created: 10-07-2026 · Last updated: 10-07-2026_

Дериват сессии [H457](https://github.com/gasyoun/Uprava/blob/main/handoffs/H457-Opus_VisualDCS_titov_parametric_core_dictionary_side_10.07.26.md).
Исполнитель: Opus 4.8 (`claude-opus-4-8`).

Первое применение **параметрического анализа лексики** воронежской школы
(В. Т. Титов, А. А. Кретов) к санскриту **со стороны словаря**, и его сверка с
**корпусным** ядром В. В. Леонченко (Прил. 10, 435 лемм) из
[`derived-data/Lexical-Cores/`](https://github.com/gasyoun/VisualDCS/blob/main/derived-data/Lexical-Cores/README.md).

Это **новая, отдельная папка**: данные Леонченко в `derived-data/` — исходники, они не
трогались и не перезаписывались.

## Колонки `pwg_parametric_core.tsv`

| Колонка | Параметр Титова | Операционализация |
|---|---|---|
| `k1` | — | заголовочное слово PWG в SLP1 |
| `hom` | — | сколько омонимичных статей слито в строку |
| `len` | **функциональный** | длина `k1` в знаках SLP1 (меньше = ядернее) |
| `senses` | **эпидигматический** (у Титова — внутрисловная деривационная активность) | число нумерованных значений `N〉` (нерасчлененная статья = 1) |
| `glosses` | эпидигматический, вариант | число глосс {% raw %}`{%…%}`{% endraw %} |
| `deriv` | деривационный, межсловная продуктивность | сколько заголовочных слов PWG содержат `k1` как подстроку |
| `phrases` | **синтагматический**, вариант (а) | число многословных санскритских цитат `{#… …#}` в статье |
| `glosswords` | **синтагматический**, вариант (б) — способ самого Титова | минимальное число немецких слов в глоссе (меньше = проще и шире семантика) |
| `syn` | **парадигматический** | мощность объединенного синонимического ряда по [`kosha_syn.jsonl`](https://github.com/gasyoun/SanskritLexicography/blob/master/RussianTranslation/src/kosha_syn.jsonl) (амаракоша и родственные тезаурусы) |
| `nsets` | парадигматический, вариант | число синонимических рядов, куда входит слово |
| `entry_chars` | **КОНТРОЛЬ** | размер статьи в знаках |
| `corpus_freq` | эталон-потолок | суммарная частота в корпусе DCS |
| `in_gold` | эталон | 1 = лемма входит в ядро Леонченко (394 из 435 отображаются в PWG) |

## Как воспроизвести

```
python Uprava/research/titov_parametric_core.py      # строит TSV + список GAP
python Uprava/research/titov_control_entry_size.py   # контроль на размер статьи
python Uprava/research/titov_length_recheck.py       # перепроверка §4-тер
```

Скрипты детерминированы и не ходят в сеть. Только чтение `csl-orig`.

## Главное, что из этих данных следует

Колонка `entry_chars` — **не служебная**. Сырой размер статьи восстанавливает корпусное
ядро лучше (35.5 %), чем любой из четырех параметров Титова (лучший — `phrases`, 33.5 %).
При выравнивании по размеру статьи эпидигматический параметр **меняет знак**. Полный
разбор и оговорки:
[`Uprava/research/slovar-kak-obekt-dissertacii.md`](https://github.com/gasyoun/Uprava/blob/main/research/slovar-kak-obekt-dissertacii.md) §4-quater.

Числа из этой таблицы нельзя цитировать без §4-quater: `syn` **циркулярен** (амаракоша —
сама по себе тезаурус ядерной лексики: 68.5 % ядра против 7.9 % словаря имеют синонимы),
а `senses`/`glosses`/`phrases` в абсолютном виде — во многом прокси размера статьи.
