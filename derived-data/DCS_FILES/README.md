# DCS_FILES — сырые архивы Digital Corpus of Sanskrit

_Created: 05-07-2026 · Last updated: 05-07-2026_

## Что внутри

Разбитые на части 7z-архивы исходных данных DCS (Digital Corpus of Sanskrit)
и производный количественный анализ:

| Файл/папка | Содержимое |
|---|---|
| [`lex.7z.7z.001-003`](lex.7z.7z.001) | многотомный архив лексики DCS (сплит на части — собирается через `7z x lex.7z.7z.001`) |
| [`lex2.7z.7z.001-005`](lex2.7z.7z.001) | вторая/расширенная версия лексического архива |
| [`sdm4arc.7z.7z.001-004`](sdm4arc.7z.7z.001) | архив данных (вероятно, экспорт из DCS-инфраструктуры `sdm4`) |
| [`spp/`](spp) | распакованная папка (не сэмплирована подробно) |
| [`Handled/`](Handled) | папка с уже обработанными/использованными файлами |
| [`Works-Share-DCS/`](Works-Share-DCS) | рабочие материалы, относящиеся к DCS |
| [`Квантитативный анализ DCS.xlsx`](Квантитативный анализ DCS.xlsx) | производный количественный анализ (binary, не сэмплирован) |

## Схема данных

Не проверялась — большинство файлов либо являются сырыми многотомными 7z-архивами
(не распаковывались в этом проходе), либо бинарными `.xlsx`. Чтобы посмотреть
реальное содержимое, нужно сначала собрать архив:

```bash
7z x lex.7z.7z.001   # соберёт и распакует lex.7z.7z.001/002/003 автоматически
```

## Как использовать

```bash
cd derived-data/DCS_FILES
7z x lex.7z.7z.001
7z x lex2.7z.7z.001
7z x sdm4arc.7z.7z.001
```

## Известные ограничения

- Это единственная папка в `derived-data/`, где основной контент — сырые
  многотомные архивы, а не готовые табличные датасеты; распаковка не
  выполнялась в этом проходе, так что внутренняя схема архивов не подтверждена.
- Провенанс/генерирующий скрипт не найден.

## Происхождение

Судя по названию (`DCS_FILES`) и содержимому (`lex`, `sdm4arc`) — это, вероятно,
исходный экспорт из [Digital Corpus of Sanskrit](http://www.sanskrit-linguistics.org/dcs/index.php),
а не производный анализ VisualDCS. Не найдено ссылок на генерирующий скрипт
в репозитории.
