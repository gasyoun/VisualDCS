# Chasticy — несклоняемые части речи (частицы, наречия, союзы)

_Created: 05-07-2026 · Last updated: 05-07-2026_

## Что внутри

Один файл: [`Комбинации несклоняемых частей речи.xlsx`](Комбинации несклоняемых частей речи.xlsx)
(Excel, бинарный формат — не читается как текст). Судя по названию, workbook
изучает **комбинации несклоняемых частей речи** санскритского корпуса —
частицы (avyaya), наречия, союзы и их сочетания друг с другом в текстах
Digital Corpus of Sanskrit (DCS).

## Схема данных

Не проверялась построчно (файл бинарный `.xlsx`, содержимое не сэмплировано в
этом проходе). По аналогии с соседними папками ([Lexical-Cores](../Lexical-Cores/README.md))
ожидаемая структура — один или несколько листов с колонками вида
`форма / частота / период / текст-источник`, но это предположение по
названию файла, не подтвержденное чтением ячеек.

## Как использовать

```python
import pandas as pd
xl = pd.ExcelFile("derived-data/Chasticy/Комбинации несклоняемых частей речи.xlsx")
print(xl.sheet_names)
df = xl.parse(xl.sheet_names[0])
```

Откройте файл вручную (Excel/LibreOffice) или через `pandas`, чтобы увидеть
реальные колонки — этот README не подтверждает точную схему.

## Известные ограничения

  файловой системы, в отличие от папок с несколькими `.xlsx` на разные срезы.
