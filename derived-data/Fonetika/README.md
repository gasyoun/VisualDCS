# Fonetika — алфавиты и лигатуры санскритского корпуса

_Created: 05-07-2026 · Last updated: 06-07-2026_

> **Канонический, воспроизводимый источник — [`regen-2026/`](regen-2026).**
> Скриптовая перегенерация акшар / варн / лигатур из корпуса DCS (4.24 млн слов),
> с provenance и кросс-проверкой против таблиц ниже (совпадение топ-20 лигатур 19/20).
> Файлы `.xlsx` в этой папке — исходные, без генерирующего скрипта; для
> переиспользования берите CSV из `regen-2026/`.

## Что внутри

| Файл | Содержимое |
|---|---|
| [`Все лигатуры.xlsx`](Все лигатуры.xlsx) | полный список лигатур (конъюнктов деванагари), встречающихся в корпусе |
| [`Двухсимвольные лигатуры.xlsx`](Двухсимвольные лигатуры.xlsx) | подмножество — лигатуры из двух символов |
| [`Исходные данные алфавитов.xlsx`](Исходные данные алфавитов.xlsx) | базовые алфавитные данные, вход для частотного анализа |
| [`Частотные алфавиты Санскрита по периодам.xlsx`](Частотные алфавиты Санскрита по периодам.xlsx) | частотность букв/лигатур по историческим периодам корпуса |
| [`Works-Share-Lig/`](Works-Share-Lig) | рабочие материалы по лигатурам |

Тема папки — фонетический/графемный анализ: какие буквы и лигатуры
деванагари встречаются в корпусе, как часто, и как это меняется по периодам.

## Схема данных

Не проверялась построчно (все основные файлы — бинарные `.xlsx`). По
названиям листов и файлов ожидаемые колонки — `лигатура/буква`,
`частота`, `период` — но это не подтверждено чтением ячеек в этом проходе.
