## Схема данных (подтверждено сэмплом)

[`Анализ глагольных форм.txt`](Анализ глагольных форм.txt) — свободный текст,
не таблица:

```
Всего глаголов, имеющих описательный перфект: 162
Относительно всех глаголов: 1,7% от всех глаголов корпуса (9445)
эти глаголы встречаются в 339 формах.
Всего глагольных форм в корпусе: 781616
Всего случаев употребелния О.П. 3668 в 2498 строфах
```

Это дает три опорных числа для всей папки: **9445** глаголов, **781616**
глагольных форм и **162** глагола с описательным перфектом (О.П.) в корпусе.

`Bazadannyh-glagolnyh-form-Korpusa/dcs_ppp_verified.md` упоминается в
[INDEX.md](../INDEX.md) как связанный с верификацией пассивного перфективного
причастия (PPP) — единственная прямая связь с родительским индексом,
найденная для этой папки.

## Как использовать

```python
# Текстовая сводка — читается напрямую
with open("derived-data/Glagolnye-formy/Анализ глагольных форм.txt", encoding="utf-8") as f:
    print(f.read())

# Табличные данные — через pandas
import pandas as pd
df = pd.read_excel("derived-data/Glagolnye-formy/Глагольные формы в Корпусе.xlsx")
```

## Известные ограничения

- **Расширение вводит в заблуждение**: `Частота появления глагольных форм в
  корпусе (Предварительные данные).csv` — это на деле бинарный OLE/Excel
  файл (подтверждено попыткой прочитать его как текст — вернулась бинарная
  каша), а не CSV. Открывать через `pandas.read_excel`, не `read_csv`.
- Название файла явно помечено «Предварительные данные» — не финальный релиз.
- Провенанс/генерирующий скрипт для большинства файлов не найден; репозиторий
  содержит только это готовые данные, без видимого кода, который их создал.
