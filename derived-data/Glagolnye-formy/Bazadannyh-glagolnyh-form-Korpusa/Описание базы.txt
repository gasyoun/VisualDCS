База данных содержит следующие файлы:
1.	Verbal_ Forms_oly.xlsx. 
	Файл содержит все глагольные формы из корпуса (за небольшим исключением)
	с указанием классов глагольных основ и ссылками на примеры употребления;
2.	TextLines.txt - Файл содержит 621445 текстовых строк из санскритских текстов.
	формат файла: номер строки, номер главы, строка, строфа, станца.
3.	Chapters.txt. Содержит список глав санскритских текстов, записанных в следующей формате:
	ID,TextID,ChapterName,Revision,Position,Date1,Date2
4.	TextNames.txt.. Файл содержит названия текстов и их параметры, записанные в следующем виде:
	"Textname","Author","Subtit","Shorthand","Comment","Publish","Place of publication","Release year","Publishing","Range","Digitizers","LanguageID","Habil Etym TimeSlot","TextCompleted","SubjectID","secondary_literature","NrOfWords"
5. 	VEXAMPLE_ID.csv Файл содержит указатели на примеры для глагольных форм. Каждая строка
	файла соответствует по номеру строке из файла Verbal_ Forms_oly.xlsx. и содержит список
	номеров строк из файла TextLines.txt.
