## Схема данных (подтверждено сэмплом)

[`Статистика по производным.txt`](Статистика по производным.txt) — свободный
текст со сводными числами:

```
Производящие с длиной 1-5 звуков: 1689
Производящие с длиной  6   звуков: 244
Производящие с длиной 7-8 звуков: 139

Производных от основ 1-5: словарь- 5635; корпус- 3790
Производных от основ 6   : словарь- 448; корпус 256
Производных от основ 7-8 : словарь- 230; корпус-  155

итого
Всего производящих основ 2072
```

Это даёт опорные числа: **2072** производящих основы, из которых
производные слова подсчитаны отдельно по словарю и по корпусу.

## Как использовать

```python
# Текстовая сводка
with open("derived-data/Imennye-formy/Статистика по производным.txt", encoding="utf-8") as f:
    print(f.read())

# Табличные данные
import pandas as pd
df = pd.read_excel("derived-data/Imennye-formy/База данных по окончаниям основ имен.xlsx")
```

## Известные ограничения

- Большинство файлов — бинарные `.xlsx`/`.ods`, точная схема столбцов не
  подтверждена построчным чтением в этом проходе.
- Названия файлов с числовыми суффиксами (`Производные 2.xlsx`,
  `Значения 1.xlsx`, `Эпицигма 1.xlsx`) намекают на итеративные черновики —
  не всегда очевидно, какая версия финальная.
- Провенанс/генерирующий скрипт не найден.
