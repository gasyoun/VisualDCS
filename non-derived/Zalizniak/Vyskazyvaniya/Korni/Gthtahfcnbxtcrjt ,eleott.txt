Утверждение **«Футурум 2 (перифрастический): имя деятеля на *-tar- в N sg + связка *as 'быть' (кроме 3-го лица, где без связки)»** является **точным, но неполным**. Оно верно описывает структуру **одной из двух разновидностей** перифрастического будущего, но упускает важный нюанс, касающийся **основы** имени деятеля.

Проверим это утверждение детально, реконструируя формы на основе корней из вашего файла `rt.txt`.

### 1. Разбор утверждения по компонентам

Утверждение описывает **Аналитическое будущее** (также называемое Futurum Exactum или Periphrastic Future).

| Компонент | Утверждение | Реальность в санскрите |
| :--- | :--- | :--- |
| **Основа** | Имя деятеля на **-tar-** | **Не всегда.** Для простых корней основа строится с суффиксом **-tṛ́-** (Guṇa корня + *tṛ*). Но для каузативов и дезидеративов суффикс другой — **-iṣṇú-** или аналитическая форма с инфинитивом. |
| **Форма имени** | **N sg** (Именительный падеж ед.ч.) | Верно. Окончание Nom. sg. для основ на *-tṛ* — **-ā** (Vṛddhi). |
| **Связка** | *as* (быть) | Верно для **1-го и 2-го лица**. |
| **3-е лицо** | Без связки | **Верно.** |

### 2. Проверка на основе корней из `rt.txt`

Возьмем простые корни и построим форму 1-го лица (где связка есть) и 3-го лица (где связки нет).

#### А. Схема построения для простых корней (Guṇa + tṛ)

Для образования основы берётся корень в ступени **Guṇa**, к нему добавляется суффикс **-tṛ**, а затем окончание Nom. sg. **-ā** (по правилу Vṛddhi: *tṛ + ā = tā*).

| Корень из файла | Guṇa | Основа имени деятеля | Nom. sg. (Имя деятеля) | + Связка (1 sg) | Результат (Я буду делать) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **kṛ** (делать) | **kar-** | `kar-tṛ` | **kartā́** | + asmi | **kartā́smi** |
| **vad** (говорить) | **vad-** | `vad-i-tṛ` | **vaditā́** | + asi (2 sg) | **vaditā́si** |
| **ji** (побеждать) | **je-** | `je-tṛ` | **jetā́** | + asmi | **jetā́smi** |
| **bhū** (быть) | **bhav-** | `bhav-i-tṛ` | **bhavitā́** | + smaḥ (1 pl) | **bhavitā́smaḥ** |

**Для 3-го лица (утверждение говорит: "без связки"):**
Форма 3 sg. = просто Nom. sg. имени деятеля.
*   `kṛ` -> **kartā́** (Он сделает).
*   `bhū` -> **bhavitā́** (Он будет/станет).
*   `vad` -> **vaditā́** (Он скажет).

✅ **Эта часть утверждения полностью верна.** 3-е лицо действительно не требует *asti* / *santi*.

### 3. Критическое уточнение: Каузативы и дезидеративы (чего не хватает в утверждении)

Утверждение создает впечатление, что **всегда** используется **-tar-**. Это не так для производных основ.

Если мы возьмем корень из файла и поставим его в **каузатив**, то перифрастический футурум образуется **иначе**: не через имя на *-tṛ*, а через **имя деятеля на -uka** (или реже описательно через инфинитив).

**Пример с корнем `kṛ` (делать) -> каузатив `kāráyati` (заставлять делать):**
*   Утверждение предполагает: *kārayitā́* (неправильно для 3 л., либо форма будет значить "он будет побудителем").
*   Реальная форма Перифрастического будущего от каузатива: **kārayitā́** + связка (для 1, 2 л.), но для 3 л. часто используется форма на **-iṣyati** (простое будущее) или описательная конструкция.

В **классическом санскрите** для каузативов (которые составляют значительную часть файла `rt.txt`, например, `kāray`, `pāṭhay`, `bodhay`, `veday`) перифрастический футурум 3-го лица часто выглядит как **kārayitā** (что **совпадает** с Nom. sg. от *kārayitṛ*), но в женском роде и среднем может использоваться форма на **-iṣyat**.

### 4. Уточнение про "Связка *as"

Утверждение говорит: "связка *as*". Это верно, но в санскрите эти формы **сливаются** с именем в одно фонетическое слово (сандхи):
*   `kartā́` + `asmi` = **kartā́smi**.
*   `kartā́` + `asi` = **kartā́si**.
*   `kartā́` + `svaḥ` = **kartā́svaḥ**.

В 3-м лице связки действительно **нет**. Это резко отличает санскрит от, например, хинди, где связка есть и в 3-м лице (*vah karegā*).

### 5. Проверка "Имя деятеля на -tar- в N sg"

Это **точное описание морфологии**.
Суффикс: **-tṛ** (в слабой ступени *-tṛ*, в сильной *-tār*).
Nom. sg. m.: **-tā** (из *tār-s* > *tā*).

**Примеры из файла:**
*   `dā` (давать) -> `dātā́` (он даст).
*   `pā` (пить) -> `pātā́` (он выпьет).
*   `nī` (вести) -> `netā́` (он поведет).
*   `śru` (слышать) -> `śrotā́` (он услышит).

Все эти корни есть в `rt.txt`, и все они подчиняются этому правилу.

### 6. Итоговая проверка

| Часть утверждения | Статус | Комментарий на основе `rt.txt` |
| :--- | :---: | :--- |
| Имя деятеля на **-tar-** | ✅ **Верно** (для простых глаголов) | `kṛ` -> `kartā`, `dā` -> `dātā`. |
| ...в **N sg** | ✅ **Верно** | Окончание **-ā**. |
| + связка **as** | ✅ **Верно** | `kartā́smi`, `dātā́si`. |
| ...кроме **3-го лица** | ✅ **Верно** | `kartā́` (он сделает), `dātā́` (он даст). |
| **Универсальность -tar-** | ⚠️ **Требует уточнения** | Для каузативов и дезидеративов структура сложнее (часто заменяется простым будущим на *-iṣyati*). |

### Общий вывод

Утверждение **корректно** как описание **перифрастического будущего для простых (первичных) глаголов** в санскрите. Оно безупречно с точки зрения базовой грамматики и легко проверяется на корнях типа `kṛ`, `bhū`, `dā`, `ji` из файла `rt.txt`. Единственный недостаток — оно не упоминает, что для производных основ (каузативов) эта модель часто вытесняется сигматическим будущим.
