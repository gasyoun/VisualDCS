Это утверждение представляет собой компактное изложение системы окончаний 3-го лица множественного числа в санскрите, и оно почти полностью верно, но содержит одну серьёзную неточность в части первичных окончаний тематического спряжения, а также требует уточнения по поводу окончания -ur.

Проверим его детально на основе корней из вашего файла rt.txt.

1. Первичные окончания (Настоящее время): *-anti (атем.) / *-nti (тем.)
Это самое слабое место утверждения.

Для атематического спряжения:

Утверждение: -anti.

Реальность: -anti (для класса 2) или -ati (для редуплицированных класса 3).

Пример из файла: ad (есть) -> adánti (они едят). as (быть) -> sánti (они суть).

Вердикт: Верно для большинства атематических классов (кроме 3-го, см. ниже).

Для тематического спряжения:

Утверждение: *-nti.

Реальность: -anti.

Критическая ошибка в утверждении: Утверждение предполагает, что тематический гласный *-a-* отбрасывается перед -nti. Это не так. Тематическая основа сохраняет *-a-*, и происходит стяжение -a- + -nti = -anti.

Реконструкция по файлу:

Корень bhū (1 кл.): основа bháva- + nti = bhávanti (они становятся).

Корень likh (6 кл.): основа likhá- + nti = likhánti (они пишут).

Корень nṛt (4 кл.): основа nṛ́tya- + nti = nṛ́tyanti (они танцуют).

Исправление утверждения: В тематическом спряжении первичное окончание -anti (внешне совпадает с атематическим, но включает тематический гласный *a*). Форма без гласного (*-nti) в санскрите не зафиксирована.

2. Вторичные окончания (Имперфект): *-an (атем.) / *-n (тем.)
Эта часть утверждения полностью верна.

Для атематического спряжения:

Утверждение: -an.

Реальность: -an (после согласных) или -n (после гласных основы).

Реконструкция по файлу:

ad (есть): Имперфект = ādan (они ели). ā- (аугмент) + ad + -an.

as (быть): Имперфект = āsan (они были). ā- + as + -an.

Для тематического спряжения:

Утверждение: -n.

Реальность: Тематический гласный *-a-* отбрасывается перед вторичным окончанием, поэтому остаётся просто -n.

Реконструкция по файлу:

bhū (1 кл.): Имперфект = abhavan (они становились). Основа abhava- + n = abhavan.

likh (6 кл.): Имперфект = alikhan (они писали). Основа alikha- + n = alikhan.

Сравнение тематического первичного и вторичного:
Это ключевое правило, которое утверждение пыталось сформулировать:
bhávanti (наст. вр.) vs ábhavan (прош. вр.) -> anti vs an.
Внешне это выглядит как -nti vs -n. Но в -nti тематический *a* всё же присутствует.

3. Редуплицированные основы класса 3: *-ati и *-ur*
Эта часть утверждения абсолютно точна и является важным исключением из общих правил.

Корни класса 3 из вашего файла:

dā (давать) -> не класс 3.

dhā (класть) -> класс 3: dádhāti.

hu (жертвовать) -> класс 3: juhóti (есть в файле).

bhṛ (нести) -> класс 3: bibhárti (есть в файле).

Первичное окончание (Наст. вр.) = -ati (вместо -anti):

Утверждение: -ati.

Реальность: Окончание 3 pl у корней 3 класса — -ati, а не -anti. (Происходит выпадение носового *-n-*).

Реконструкция по файлу:

hu: júhvati (они жертвуют).

dhā: dádhati (они кладут).

bhṛ: bíbhrati (они несут).

Вторичное окончание (Имперфект) = -ur (вместо -an):

Утверждение: -ur.

Реальность: Используется специальное окончание перфектного типа -ur.

Реконструкция по файлу:

hu: ajuhavur (они жертвовали).

dhā: adadur (они клали).

bhṛ: abibharur (они несли).

Итоговая проверка утверждения
Часть утверждения	Оценка	Комментарий на основе rt.txt
Первичное атем. -anti	✅ Верно	ad -> adanti
Первичное тем. *-nti	❌ Неверно	Должно быть -anti. bhū -> bhavanti (а не bhavnti).
Вторичное атем. -an	✅ Верно	ad -> ādan
Вторичное тем. -n	✅ Верно	bhū -> abhavan
Редупл. класс 3 первич. -ati	✅ Верно	hu -> juhvati
Редупл. класс 3 вторич. -ur	✅ Верно	hu -> ajuhavur
Общий вывод: Утверждение содержит одну критическую неточность в отношении тематического первичного окончания, но блестяще точно описывает вторичные окончания и исключения для 3-го класса. Если исправить *-nti на *-anti, утверждение станет безупречным справочным правилом.
